Plugins

A plugin is a directory that adds task types, tools or MCP endpoints. System plugins are installed by operators and shared with everyone unless they limit who may use them; plugins in your sandbox are yours only. A plugin that provides several kinds is listed in each group.

MCP

An MCP endpoint is a server whose tools the agent can call. Plugins install some, shared with everyone unless the plugin limits them. Endpoints you add are yours: only you see them until you share them, and each of their tools can be enabled, shared or hidden on its own. Adding an endpoint asks it for its tools.

Tools

Every tool your tasks can use, and where it comes from: the agent itself, the system, a plugin or an MCP endpoint. Switch off a tool, or every tool of a plugin or an endpoint, to keep it out of your tasks; nobody else is affected. Tools come with plugins and MCP endpoints (add yours on the MCP tab); skills are on their own tab.

Knowledge

Knowledge bases the agent searches for your tasks (kb_search, kb_read, kb_grep, kb_research). The system knowledge service is configured by operators; services you connect are yours only and are reached with their own token. Switch off a service or a single knowledge base to keep it out of your tasks. Documents are added in the knowledge service's own pages.

Skills

A skill is a set of instructions for one kind of work, such as release notes or a review checklist. The agent sees the skills closest to each request and loads one when it fits; the skill's instructions then guide the task, and the tools it names are the only ones offered. Skills you add are yours: only you see them until you share them.

Memory

What the agent remembers about you from your earlier tasks: your preferences, facts about your environment, decisions that matter again. It recalls the most relevant at the start of each task and can search the rest. Only your tasks see your memories. Delete what is wrong or that you would rather it forgot.

Personal access tokens

A token lets the agenticwf command line and your scripts act as you without the browser sign-in. It carries all your permissions, so treat it like a password: one per machine or job, the shortest expiry that works, and revoke it when you no longer need it.

Groups

Groups are how you share with a team: a knowledge base or a document with groups visibility is shared with the groups you name. Ask to join a group; its admins approve requests and manage its members. A change applies within a minute, without signing in again.
